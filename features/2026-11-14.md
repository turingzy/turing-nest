# 2026-11-14

## 变更内容

### 构建与引擎升级 (Hugo 0.170.0)
- 升级静态站点生成器至 Hugo v0.170.0，全面适配官方统一二进制架构（移除已废弃的 LibSass/Extended 分支构建），更新 `hugo.toml` 中与 Cloudflare Pages 保持版本一致的声明
- 修复语言配置废弃警告：将 `hugo.toml` 中的旧版配置 `languageCode = 'zh-CN'` 规范迁移为根级 `locale = 'zh-CN'`
- 现代化模板语言 API：全面替换全站 10 处模板文件中的废弃变量，将 `.Site.LanguageCode` 替换为 `.Site.Language.Locale`，将 `.Site.Language.LanguageName` 替换为 `.Site.Language.Label`，达成零警告（0 warnings）干净构建

### 性能与 Core Web Vitals (CWV)
- 优化游戏库页面（`themes/yinyang/layouts/games.html`）：针对首屏展示的最新游戏封面显式声明 `loading="eager"` 与 `fetchpriority="high"`，显著提升游戏专页 LCP 分数
- 优化摄影专页（`themes/yinyang/layouts/photography.html`）：对首屏前 3 张关键作品赋予 `fetchpriority="high"` 与 `loading="eager"` 优先加载，后续瀑布流照片保持原生懒加载
- 优化文章内 Markdown 图片（`themes/yinyang/layouts/_default/_markup/render-image.html`）：首图 (`.Ordinal 0`) 自动标记 `fetchpriority="high"` 与 `loading="eager"`，杜绝与关键资源抢占带宽；其余正文图片保留异步解码与原生懒加载
- 优化长列表渲染性能（`themes/yinyang/assets/css/index.css`）：为首页年份与文章列表区块引入 `content-visibility: auto`，大幅降低非视口长内容的初次重排与渲染成本

### 现代 Web 顶层组件与交互 (Top Layer)
- 重构全局搜索弹窗（`themes/yinyang/layouts/partials/search.html`）：基于原生 HTML `<dialog>` 与 `::backdrop` 伪元素实现浏览器原生 Top Layer 渲染，由浏览器底层接管层级（z-index）管理与焦点陷阱（Focus Trap）
- 重构外链离开确认弹窗（`themes/yinyang/layouts/partials/scripts.html`）：基于原生 `<dialog>` 及 `<form method="dialog">` 重构，支持原生轻触背景关闭（light-dismiss）与 Esc 快捷键
- 优化热力图浮层定位（`themes/yinyang/layouts/partials/heatmap.html`）：渐进增强引入现代 CSS Anchor Positioning（锚点定位），在支持的现代浏览器中由 CSS 原生计算提示框绝对位置，免除 JavaScript 视口计算重排开销

### 评论系统 (Giscus)
- 优化 Giscus 评论区（`themes/yinyang/layouts/partials/giscus.html`）：统一配置为中文界面（`data-lang="zh-CN"`），保持亮暗主题无缝动态切换与 session 异常自动恢复机制

### 样式与阅读体验
- 优化文章目录滚动体验（`themes/yinyang/assets/css/index.css`）：隐藏目录（`.toc`）纵向/横向滚动条（`scrollbar-width: none` 及 `::-webkit-scrollbar { display: none; }`），保持内容完整可滚动的极简视觉呈现
- 优化顶部导航栏间距（`themes/yinyang/assets/css/index.css`）：收紧导航条垂直外边距（`.header-items` 由 `10px 0` 调整为 `5px 0`），使副标题、导航菜单与分割线之间的排版更加紧凑自然
